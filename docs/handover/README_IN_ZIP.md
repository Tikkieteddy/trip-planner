# Using this handover package

This ZIP contains documentation only, not application source or credentials.

1. Extract it into the root of the existing `Tikkieteddy/trip-planner` repository, preserving the `docs/handover/` folder.
2. Review `CLAUDE.md`, `HANDOVER.md`, `DOCUMENT_INDEX.md`, then `START_HERE_CLAUDE.md`.
3. Treat all `NOT VERIFIED`/`NOT FOUND` labels literally and re-check live services before operational changes.
4. The wireframes are structural and responsive illustrations of current code, not exact pixel reproductions.
5. `HANDOVER_DASHBOARD.html` works as a local file; diagrams and navigation are self-contained.
6. Do not put `.env.local`, keys, user route exports or other secrets into the package.

The source repository remains the canonical application. This archive does not include `node_modules`, build output, `.vercel` state or source assets unrelated to documentation.
